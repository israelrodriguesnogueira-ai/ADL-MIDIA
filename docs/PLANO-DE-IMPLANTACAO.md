# Plano de implantação — ADL Mídia

## Concluído
- Integração GitHub com escrita validada.
- Repositório inicializado.
- Painel web básico em index.html, com projetos e backups locais.
- Proposta recuperada documentada.
- Primeiro vídeo descrito com roteiro e storyboard.

## Próxima entrega
- Evoluir painel para etapas detalhadas: ideia, roteiro, imagens, narração, edição, revisão e publicação.
- Campos para cenas, mensagem principal, descrição, hashtags, versões e link do vídeo.
- Visualização de pendências, concluídos e calendário editorial.
- Testar interface no navegador e em celular.
- Avaliar GitHub Pages gratuito para hospedagem estática, sem credenciais ou dados privados no código.

## Futuro, condicionado a testes e autorização
- Integração com serviços de narração e vídeo.
- Armazenamento sincronizado em banco de dados.
- Automação de publicação, somente com autorização e credenciais protegidas.
- Área pública de vídeos e monetização compatível com políticas.

## Riscos
- localStorage não sincroniza entre dispositivos; exportar backup.
- Conteúdo e música exigem revisão de direitos autorais.
- Publicação em GitHub Pages torna os arquivos estáticos públicos.
- Receita não é garantida; métricas e testes precisam orientar investimentos.
