# Gerador experimental de vídeo vertical

Este protótipo usa o navegador para gerar um vídeo **sem narração automática** a partir de até seis cenas com texto. Não utiliza API paga. Requer Chrome ou Edge com suporte a MediaRecorder. O formato exportado costuma ser WebM, e não MP4.

Abra `gerador.html` em um navegador compatível, preencha os textos e clique em **Gerar vídeo**. Para adicionar voz, música, imagens próprias e legendas sincronizadas, será necessária uma etapa posterior de edição.

Não inclui upload nem publicação automática. Não use textos ou imagens de terceiros sem autorização.
